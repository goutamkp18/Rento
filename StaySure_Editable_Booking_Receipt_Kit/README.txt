STAYSURE AI - REUSABLE PG BOOKING PAYMENT RECEIPT KIT

Included files:
1. StaySure_Booking_Payment_Receipt_Template.docx
   Editable Word receipt template/reference with variable placeholders. Use it to change example fields manually or as the visual reference for Antigravity.

2. StaySure_Booking_Payment_Receipt_Template.html
   Styled HTML/CSS print layout with {{placeholder}} variables. This is the best starting point for a dynamically generated PDF in the web application.

3. ANTIGRAVITY_IMPLEMENTATION_PROMPT.md
   Copy/paste or upload this implementation brief into Antigravity. It explains the data mapping, payment verification, PDF generation, authorization, and tests.

Template behaviour:
- The PG/property name, address, owner details, student information, booking reference, booking fee, and payment references are dynamic fields.
- The same layout can be reused for every PG listing; do not hardcode a single PG's name or amount.
- Monthly rent is explicitly shown as payable later and is not included in the booking fee.
- This document is a BOOKING PAYMENT RECEIPT, not a monthly rent receipt or a tax invoice.
- It contains no pre-filled fictional PG details, transaction IDs, amounts, GST numbers, or tax values.
- A receipt should show PAID only after the payment is verified server-side.
- Optional fields such as check-in date, room/bed, owner contact, and property address should be omitted or shown as not provided if the application has no value for them.
